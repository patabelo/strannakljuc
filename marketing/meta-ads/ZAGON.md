# Zagon — 5 minut v Meta Ads Manager

Paket je pripravljen. Objaviti morate vi v svojem Meta računu (tukaj ni dostopa do vašega Ads Managerja).

## Nastavitve

| Polje | Vrednost |
| --- | --- |
| Cilj | **Traffic** → Landing page views *(ali Leads, če imate Pixel)* |
| Kampanja | `SNK \| Leads \| Cold \| SLO` |
| Ad set | `AS1 \| Advantage+ / Broad SLO` |
| Lokacija | Slovenija |
| Starost | 28–55 |
| Jezik | Slovenščina |
| Targeting | Broad / Advantage+ (brez interesov) |
| Placements | Advantage+ |
| Proračun | **8–10 €/dan** |
| Trajanje | 10–14 dni |
| Oglas | **samo AD2** |

## AD2 — prilepite

**Website URL**
```
https://strannakljuc.si/?utm_source=meta&utm_medium=paid_social&utm_campaign=snk_leads_cold&utm_content=ad2_hitrost
```

**Primary text**
```
Izdelujem spletne strani za vse — za s.p., zasebnike, mala in večja podjetja.

Od potrjenega osnutka do objavljene strani v 5–7 delovnih dneh.
Stran sestavim vnaprej — brez WordPressa, brez vtičnikov, ki bi stran upočasnili.
Dobite jasno ponudbo, kontakt, ki dela na mobitelu, in stran, ki je pripravljena za Google.
```

**Headline:** Od zamisli do objave v 5–7 dneh  
**Description:** Enostranska stran · brez agencije  
**CTA:** Learn more  

**Creative:** `creatives/meta-oglas-hitrost-4x5.jpg`

## Koraki

1. Odprite [adsmanager.facebook.com](https://adsmanager.facebook.com)
2. Create → Campaign → Traffic (Landing page views)
3. Ad set: Slovenija, 28–55, Advantage+ audience, 8–10 €/dan
4. Ad: naložite `meta-oglas-hitrost-4x5.jpg`, prilepite besedilo zgoraj, URL z UTM
5. Publish

Ko je kampanja **Active**, napišite tukaj — preverim landing in povratni tok.
